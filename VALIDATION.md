## Practical limits

Installation and UI behavior in the user's VS Code, and live inference with the user's own model server, have not been tested. The compiled-agent test validates the integration with a protocol test server, not the quality or tool-calling ability of any real model.

The active model adapter is OpenAI-compatible and effective config permits only a loopback `local` provider. Model catalogs, cloud auth loaders, cloud autocomplete/session uploads, external plugins, remote control and telemetry transports are disabled. Mandatory MIT notices are preserved.

This is application policy. VS Code, other extensions, terminal commands, local servers and separately launched browsers have their own network behavior. No operating-system firewall is installed.
